# tiny-bignum-c

tiny-bignum-c is a small multiple precision integer implementation in C. It supports only unsigned integers.

## Version

The files `bn.c` and `bn.h` were copied directly from the source code, available at <https://github.com/kokke/tiny-bignum-c>, at commit hash [2ffac69](https://github.com/kokke/tiny-bignum-c/commit/2ffac69817adbe08930befd9375d31658a8311a4).
