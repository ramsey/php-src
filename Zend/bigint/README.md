# PHP BigInt Arithmetic

PHP uses [LibTomMath](https://www.libtom.net/LibTomMath/) as the default implementation for [arbitrary-precision arithmetic](https://en.wikipedia.org/wiki/Arbitrary-precision_arithmetic) (i.e., *bigint* arithmetic, *bignum* arithmetic, *multiple-precision* arithmetic, etc.).

LibTomMath is an arbitrary-precision arithmetic library released into the public domain and also available for use under the terms of [The Unlicense](https://opensource.org/license/unlicense). For the full license and public domain dedication, see the [LICENSE](libtommath/LICENSE) file included in the `libtommath/` subdirectory. For better performance, the [GNU Multiple Precision](https://gmplib.org) library may be used instead, but it is not bundled with PHP, due to licensing concerns.

## LibTomMath

Version [v1.3.0](https://github.com/libtom/libtommath/releases/tag/v1.3.0) of LibTomMath is bundled in the PHP source code in the `Zend/bigint/libtommath/` subdirectory. The LibTomMath license and C header files are copied and included here verbatim. The file `mpi.c` is a generated file that includes all the LibTomMath C sources. It was generated by executing the `gen.pl` script included in the LibTomMath source code.

## GNU Multiple Precision

If the GMP library is included on your system, you may use it as the backend for arbitrary-precision arithmetic. This should result in better performance.

To use GMP for BigInt support, use the `--enable-bigint-gmp` configuration option when building PHP.

```bash
./configure --enable-bigint-gmp
```
